# Getting Support

MockingBird is open-source software maintained on a best-effort basis. There is
no commercial support, SLA or hosted help desk.

- **Something not working?** Start with
  [docs/troubleshooting.md](docs/troubleshooting.md): in-app status, Doctor,
  common problems, recovery, and how to gather a support bundle safely.
- **What is and is not supported?** [docs/support-matrix.md](docs/support-matrix.md).
- **Using it:** [docs/using-mockingbird.md](docs/using-mockingbird.md).
- **Found a bug?** Open an issue using the **Bug report** form.
- **Security vulnerability?** Do **not** open a public issue; follow
  [SECURITY.md](SECURITY.md).
- **Want to contribute?** [CONTRIBUTING.md](CONTRIBUTING.md).
